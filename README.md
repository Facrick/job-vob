# QA Smart Assistant Pro

Десктоп-приложение (Flet) для поиска QA-вакансий на hh.ru, генерации
сопроводительных писем через LLM (Groq), тренировки собеседований,
аналитики зарплат и встроенного учебника QA.

## Возможности

- **CRM-воронка** — поиск вакансий на hh.ru и отслеживание их по статусам
  (новая → письмо готово → отклик → собеседование → оффер/отказ).
- **Письма** — генерация сопроводительного письма по резюме и описанию
  вакансии, доработка по фидбеку, автоотклик.
- **Интервью** — тренировочное техническое собеседование с ИИ.
- **Аналитика** — гистограмма распределения зарплат по собранным вакансиям.
- **Учебник QA** — справочник вопросов с ответами.

## Стек

Python · Flet (UI) · Playwright (парсинг) · BeautifulSoup · Groq (LLM) ·
SQLite · matplotlib · pypdf

## Установка

```bash
# 1. Виртуальное окружение
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS

# 2. Зависимости
pip install -r requirements.txt

# 3. Браузер для Playwright (обязательно)
playwright install chromium
```

## Конфигурация

1. Скопируйте шаблон окружения и впишите свой ключ Groq:
   ```bash
   cp .env.example .env
   ```
   `.env`:
   ```
   GROQ_API_KEY=ваш_ключ_от_console.groq.com
   PROXY_URL=          # опционально
   ```
   Ключ Groq — бесплатно на https://console.groq.com/keys

2. Положите своё резюме в корень проекта под именем **`resume.pdf`** —
   из него берётся текст для генерации писем.

## Запуск

```bash
python run_flet.py
```

При первом поиске откроется окно браузера (Playwright). Если hh.ru покажет
капчу — решите её вручную в этом окне, парсинг продолжится автоматически.

## Структура

```
core/        бизнес-логика (без UI)
  parser.py      парсинг hh.ru + автоотклик (Playwright)
  ai_engine.py   генерация писем и mock-интервью (Groq)
  database.py    репозиторий вакансий и писем (SQLite)
  handbook.py    загрузка учебника из data/handbook.json
  config.py      настройки и промпты
  models.py      статусы вакансий (VacancyStatus)
  utils.py       парсинг зарплат, HTML→Markdown
gui/
  flet_views.py  представление (вкладки, виджеты)
  controllers.py контроллер (связывает UI и core)
run_flet.py    точка входа
data/          БД, настройки, учебник (не в git)
```

## Замечания

- Парсинг hh.ru через браузер — для личного использования. Учитывайте
  условия использования hh.ru; для интеграции предпочтительнее официальный
  API `api.hh.ru`.
- Файлы `.env`, `data/`, `logs/`, `covers/`, `resume.pdf` в `.gitignore`
  и не попадают в репозиторий.
